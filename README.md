NewtonX-TeraChem Interface for Non-Adiabatic DynamicsThis repository contains a refactored and robust Perl script, run-tera-cas.pl, that serves as a communication layer between the NewtonX dynamics software and the TeraChem quantum chemistry package.The interface is designed to handle non-adiabatic dynamics simulations using several electronic structure methods available in TeraChem, including CASSCF, FOMO-CASCI, and TDA/TDDFT.CompatibilityThis interface has been tested and is confirmed to work with the following software versions:NewtonX: 2.4TeraChem: 1.9Key FeaturesBroad Method Support: Capable of running dynamics with CASSCF, FOMO-CASCI, and TDA/TDDFT to calculate energies, gradients, and non-adiabatic couplings (NACs).Note: RPA/TDDFT is not supported for NAC calculations as they are not generated by TeraChem.Automatic Archiving: At each time step, the script automatically saves key information for analysis and restarting:Molecular orbitals are archived as Molden files in INFO_RESTART/MOLDEN_ARCHIVE/.Wavefunction coefficients are saved in INFO_RESTART/WF_ARCHIVE/.Robust Error Handling: Includes checks for common calculation failures and provides clear error messages.Detailed Output: Prints formatted energies, gradients, and NACs to standard output at each time step for easy monitoring.Installation and PrerequisitesBefore using the script, you must configure NewtonX to recognize it as a valid program interface.Locate colib_perl.pm: Open the colib_perl.pm file, which is typically located in the $NX/lib/ directory, where $NX is the environment variable pointing to your NewtonX installation.Add Program Definition: Add the following Perl code block to the colib_perl.pm file. This defines "program 21.0" as the TeraChem interface.if (($prog >= 20.95) and ($prog < 21.05)){
      %progconf=(progname     => "terachem",
                  methodname => "terachem",
                  ic         => "y",
                  dyn        => "y",
                  hyb        => "n",
                  ip         => "n",
                  key        => sprintf("%4.1f",21.0),
                  label      => "Terachem",
                  method     => "CASSCF/FOMO_CASCI/DFT",
                  parfile    => "terachem.par",
                  nad_exec   => "y",
                  lvprt_d    => 1,
                  vdoth_d    => 0,
                  never_state_d  => 0,
                  cio_options_d  => "NULL",
                  cisc_options_d => "NULL",
                  cprog_d    => 0,
                  progic     => "",
                  progdyn    => "run-tera-cas.pl");
}
Place the Script: Copy the run-tera-cas.pl script into your NewtonX bin directory ($NX/bin/).Running a TrajectoryTo start a non-adiabatic dynamics simulation, you need to set up a trajectory directory with a specific structure and set of input files.Set prog in control.dyn: In your main dynamics control file (control.dyn), set the prog parameter to 21.0 to tell NewtonX to use this TeraChem interface.prog = 21.0
Directory Structure: Your trajectory directory (e.g., TRAJ_01) must contain the following files and subdirectories:TRAJ_01/
├── control.dyn      # Main NewtonX dynamics parameters
├── sh.inp           # Surface hopping parameters
├── geom             # Initial geometry (in Bohr)
├── veloc            # Initial velocities (in atomic units)
└── JOB_NAD/         # Directory for non-adiabatic calculations
    ├── GRAD/
    │   └── start.sp # TeraChem template for gradient calculations
    ├── NAD_N1N0/
    │   └── start.sp # Template for NAC with state below
    └── NAD_N1N2/
        └── start.sp # Template for NAC with state above
TeraChem Templates (start.sp):The start.sp files are your TeraChem input templates. You must specify the electronic structure method (CASSCF, TDA, etc.), basis set, and all other relevant quantum chemistry parameters within these files. The run-tera-cas.pl script will automatically modify these templates at each time step to update the geometry, target states, and wavefunction guess.
